# Pocket CO Monitor - Portable Carbon Monoxide Detector

A compact, USB/battery-powered pocket carbon monoxide (CO) detector using ESP32, MQ-7 sensor, and 0.96" OLED display.

![Circuit Diagram](circuit-diagram.png)

## Features
- Pocket-sized CO monitoring
- USB + rechargeable battery power
- Real-time percentage display with SAFE/WARN/DANGER status
- Audio alerts
- Wokwi simulation support

## Files
- pocket_co_monitor.ino - Arduino code
- diagram.json - Wokwi circuit
- circuit-diagram.png - Circuit diagram
- README.md - Project documentation

## Usage
1. Upload pocket_co_monitor.ino to ESP32
2. Assemble circuit as per diagram
3. Power on and wait ~60s for warm-up

**Note:** This is for educational/demo use only, not a certified life-safety device.
